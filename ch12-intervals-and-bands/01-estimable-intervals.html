12.1  Intervals for estimable functions

A point estimate needs a statement of its precision. A confidence interval gives one exactly: a range computed from the data that contains the unknown quantity with a probability fixed in advance. This section builds the interval for one estimable function, relates it to the t test, and records two facts that are easy to overlook: an interval for a non-estimable function is useless, and the interval for σ2, unlike the one for a coefficient, depends delicately on normality.

Throughout the chapter we work in the normal linear model Y∼Nn(Xβ,σ2I),β∈Rp, σ2>0, of Eq. 7.3.1, with r=rank(X)<n. We write G for any generalized inverse of X⊤X, β^ for any least squares estimate, SSE=‖(I−M)Y‖2 and s2=SSE/(n−r). For 0<γ<1, tν,γ, Fγ(q,ν) and χγ2(ν) denote the upper γ points of t(ν), F(q,ν) and χ2(ν).

12.1.1. Confidence sets

Definition 12.1.1 (Confidence set)

Let θ=g(β,σ2) be a quantity with values in a set Θ. A confidence set for θ with confidence level 1−α is a rule that assigns to each data vector y a subset C(y)⊆Θ, such that Prβ,σ2{θ∈C(Y)} ≥ 1−α for every β∈Rp and σ2>0. The left side is the coverage probability at (β,σ2). The set is exact if the coverage equals 1−α at every parameter value. When C(y) is an interval it is a confidence interval.

The probability is taken over Y with the parameters fixed: the set is random and the target is not. A realized interval either contains θ or it does not; 1−α describes the procedure.

The standard way to build an exact set is a pivot: a function Q(Y,θ) whose distribution is the same at every parameter value. If Pr{Q(Y,θ)∈A}=1−α for a fixed set A, then C(y)={θ0:Q(y,θ0)∈A} is exact, because the events {θ∈C(Y)} and {Q(Y,θ)∈A} are the same event. All the sets of this chapter are built this way, from pivots supplied by Chapter 7.

12.1.2. The t interval

Theorem 12.1.1 (The t interval for an estimable function)

Let λ∈C(X⊤), λ≠0, and put se(λ⊤β^)=sλ⊤Gλ. Let

I(Y)=[λ⊤β^−tn−r,α/2se(λ⊤β^),  λ⊤β^+tn−r,α/2se(λ⊤β^)].
(12.1.1)

  • (a) I(Y) does not depend on the choice of β^ or of G.

  • (b) I(Y) is an exact 1−α confidence interval for λ⊤β.

  • (c) Its length L=2tn−r,α/2sλ⊤Gλ has expectation EL=2tn−r,α/2κn−rσλ⊤Gλ, where κν=EV/ν=2νΓ((ν+1)/2)Γ(ν/2)<1,V∼χ2(ν).

  • (d) The one-sided intervals (−∞, λ⊤β^+tn−r,αse] and [λ⊤β^−tn−r,αse, ∞) are exact 1−α confidence intervals for λ⊤β.

Proof.

  • (a) Write λ=X⊤ρ. Then λ⊤β^=ρ⊤Xβ^=ρ⊤MY and λ⊤Gλ=ρ⊤XGX⊤ρ=ρ⊤Mρ by Theorem 6.3.7. Neither involves the choices, and neither does s.

  • (b) By Corollary 7.5.2, T=(λ⊤β^−λ⊤β)/se(λ⊤β^)∼t(n−r) at every (β,σ2). The event λ⊤β∈I(Y) is the event |T|≤tn−r,α/2, whose probability is 1−α. So part (b) restates Eq. 7.5.1 as a confidence statement.

  • (c) L is a constant multiple of s=σV/(n−r) with V=SSE/σ2∼χ2(n−r) (Theorem 7.5.1(b)). With the χ2(ν) density of Eq. 4.1.1, EV=∫0∞v1/2vν/2−1e−v/22ν/2Γ(ν/2)dv=2(ν+1)/2Γ((ν+1)/2)2ν/2Γ(ν/2), because the integrand is a multiple of the χ2(ν+1) density. Dividing by ν gives κν. By Jensen’s inequality EV/ν<E(V/ν)=1, with strict inequality since V is not constant.

  • (d) The events are {T≥−tn−r,α} and {T≤tn−r,α}, each of probability 1−α.

Part (a) matters when X is rank deficient: the interval is a property of the model, not of the software’s choice of generalized inverse. The degrees of freedom are n−r, not n−p.

Part (c) shows what the interval costs. Its expected length is proportional to σλ⊤Gλ, the standard deviation of the estimate. Estimating σ adds the factor tn−r,α/2κn−r in place of the normal point zα/2 that would be used if σ were known. For α=0.05 that factor is 2.45 at n−r=5 and 2.06 at n−r=20, against 1.96. Beyond about twenty residual degrees of freedom, precision improves only through λ⊤Gλ, that is, through the design.

Example (Murder rates: coefficients and a mean)

Return to the regression of the 2009 murder rate of the 50 states on the poverty rate, the percentage of single-parent households and the percentage urban, with an intercept (Example (Poverty and murder rates)). Here n=50, r=4, s2=2.217, and t46,0.025=2.013. The 95% intervals for the coefficients are

Coefficient Estimate Standard error 95% interval
intercept −9.0946 1.5555 (−12.226, −5.964)
poverty 0.2538 0.0934 (0.066, 0.442)
single parent 0.3980 0.0829 (0.231, 0.565)
urban 0.0046 0.0131 (−0.022, 0.031)

The data are consistent with anything from 0.066 to 0.442 murders per 100,000 for each point of poverty, with the other regressors held fixed in the sense of Theorem 6.6.2. The urban interval straddles zero but is narrow, which says more than “not significant”: any such association is at most 0.031 per percentage point.

A mean response is an estimable function too. For a hypothetical state with poverty 18%, single-parent households 28% and 70% urban, x0=(1,18,28,70)⊤, the estimated mean murder rate is 6.937 with standard error 0.412, and the 95% interval is (6.107, 7.767). Here x0⊤Gx0=0.0767. Section 12.3 interprets this number as the leverage of the new point.

import numpy as np
import statsmodels.api as sm
from scipy import stats

data = sm.datasets.statecrime.load_pandas().data
data = data.drop(index="District of Columbia")
y = data["murder"].to_numpy()
X = np.column_stack([np.ones(len(y)), data[["poverty", "single", "urban"]]])
n, p = X.shape
r = np.linalg.matrix_rank(X)
G = np.linalg.pinv(X.T @ X)                     # any generalized inverse will do
beta_hat = G @ X.T @ y
s2 = np.sum((y - X @ beta_hat) ** 2) / (n - r)
q = stats.t.ppf(0.975, n - r)                   # upper 2.5% point of t(n - r)


def t_interval(lam):
    """95% interval for the estimable function lam^T beta."""
    est = lam @ beta_hat
    se = np.sqrt(s2 * lam @ G @ lam)
    return est, se, est - q * se, est + q * se


for j, name in enumerate(["intercept", "poverty", "single", "urban"]):
    est, se, lo, hi = t_interval(np.eye(p)[j])
    print(f"{name:9s} {est:8.4f}  se {se:.4f}  95% interval ({lo:.3f}, {hi:.3f})")

12.1.3. What the standard error measures

For a coefficient in a full-rank model with an intercept, Eq. 6.6.2 gives se(β^j)=s‖(I−M(j))xj‖=sSjj(1−Rj2), where M(j) projects onto the span of the other columns. The interval is short when xj has a large component orthogonal to the other regressors; collinearity lengthens it through 1−Rj2.

In general λ⊤Gλ=‖Mρ‖2, with λ=X⊤ρ, is the smallest squared length of a vector a with E(a⊤Y)=λ⊤β (Theorem 7.2.1).

12.1.4. Duality with tests

An interval and a family of tests carry the same information, in any model.

Proposition 12.1.2 (Tests and confidence sets)

For each θ0∈Θ, let A(θ0) be the acceptance region of a test of H:θ=θ0 with Prβ,σ2{Y∈A(θ0)}≥1−α whenever g(β,σ2)=θ0. Then C(y)={θ0∈Θ:y∈A(θ0)} is a 1−α confidence set for θ, and it is exact if every test has size exactly α at every parameter value in its hypothesis. Conversely, if C is a 1−α confidence set, the rule “reject H:θ=θ0 iff θ0∉C(y)” is a level-α test for every θ0.

Proof. For every parameter value, with θ=g(β,σ2), the events {θ∈C(Y)} and {Y∈A(θ)} coincide, so they have the same probability. Both directions follow.

For an estimable function, the two-sided t test of λ⊤β=d accepts iff |λ⊤β^−d|≤tn−r,α/2se, which is the condition d∈I(y). So the interval Eq. 12.1.1 is exactly the set of values d that the t test of Theorem 11.6.1 does not reject. The p-value of the test of d is the smallest α for which the 1−α interval excludes d.

The interval is the more informative report. A test of βj=0 reports one bit, confounded with the sample size; the interval shows location and resolution. Exercise (B2) uses it to answer “is the effect negligible?”, which a test of βj=0 cannot answer at all.

12.1.5. Functions that are not estimable

What if λ∉C(X⊤)? The recipe above fails because λ⊤β^ depends on the choice of β^. The failure is not a defect of the recipe. No procedure can do better.

Proposition 12.1.3 (No useful interval for a non-estimable function)

Let λ∉C(X⊤) and let C be a 1−α confidence set for λ⊤β with α<1. Then at every parameter value (β,σ2) and for every real v, Prβ,σ2{v∈C(Y)}≥1−α. If the sets C(y) are such that {(y,v):v∈C(y)} is measurable, the expected length of C(Y) is infinite at every parameter value.

Proof. By Theorem 8.3.1 there is w∈N(X) with λ⊤w≠0. Fix (β,σ2) and v, and put β′=β+cw with c=(v−λ⊤β)/λ⊤w. Then Xβ′=Xβ, so Y has the same distribution under (β′,σ2) as under (β,σ2), while λ⊤β′=v. Hence Prβ,σ2{v∈C(Y)}=Prβ′,σ2{λ⊤β′∈C(Y)}≥1−α. For the length, Fubini’s theorem gives, for every a>0, E[length(C(Y)∩[−a,a])]=∫−aaPr{v∈C(Y)}dv ≥ 2a(1−α), and the left side is at most the expected length of C(Y). Let a→∞.

Thus the algebraic fact of Chapter 8 becomes a statement about inference.

12.1.6. An interval for σ2

Proposition 12.1.4 (Interval for the error variance)

The interval [ SSEχα/22(n−r) , SSEχ1−α/22(n−r) ] is an exact 1−α confidence interval for σ2, and the square roots of its endpoints give one for σ.

Proof. SSE/σ2∼χ2(n−r) at every parameter value (Theorem 7.5.1(b)), so it is a pivot. The event χ1−α/22(n−r)≤SSE/σ2≤χα/22(n−r) has probability 1−α, and it is the event that σ2 lies in the interval, which is the interval of Exercise (B3). Taking square roots is monotone.

For the murder-rate regression, SSE=46s2 with s2=2.217, the chi-squared points are 29.160 and 66.617, and the 95% interval for σ2 is (1.531, 3.497). The interval is not symmetric about s2, and it is not the shortest one with this coverage (Exercise (C2)).

The two pivots of this section react differently to non-normal errors. The t statistic needs normality of a weighted average of errors, which a central limit theorem restores, and s→σ, which holds for any error law. The chi-squared pivot needs the whole error distribution, because the variance of SSE depends on the fourth moment (Proposition 7.5.4). Take the fitted murder-rate model as the truth, with σ2=s2, and simulate 40000 data sets. With normal errors the two 95% intervals cover in proportions 0.9514 (poverty coefficient) and 0.9491 (σ2). With errors from a t(5) distribution rescaled to the same variance, the coefficient interval still covers 0.9498 of the time, but the interval for σ2 covers only 0.8165. More data do not repair this (Exercise (B3)).

x0 = np.array([1.0, 18.0, 28.0, 70.0])          # a state with high poverty and single parenthood
est0, se0, lo0, hi0 = t_interval(x0)
print(f"mean murder rate at x0: {est0:.3f}, se {se0:.3f}, interval ({lo0:.3f}, {hi0:.3f})")

sse = s2 * (n - r)
lo_s2 = sse / stats.chi2.ppf(0.975, n - r)      # interval for sigma^2 from SSE/sigma^2 ~ chi^2(n-r)
hi_s2 = sse / stats.chi2.ppf(0.025, n - r)
print(f"s^2 = {s2:.3f}; 95% interval for sigma^2 ({lo_s2:.3f}, {hi_s2:.3f})")

12.1.7. Exercises

A. Check your understanding

Exercise (A1)

A design is replicated m times: X is replaced by m stacked copies of itself. For a fixed estimable λ⊤β, how does λ⊤Gλ change? Roughly how many replicates are needed to halve the expected length of the 95% interval when n−r is already large, and why is the answer slightly less than 4 when n−r is small?

Solution. The stacked matrix has X⊤X replaced by mX⊤X, and G/m is a generalized inverse of mX⊤X, so λ⊤Gλ is divided by m. By Theorem 12.1.1(c) the expected length is proportional to tν,α/2κν/m, with ν=mn−r. For large ν the factor tκ is nearly constant and m=4 halves the length; for small ν, replication also lowers tκ, so slightly less suffices.

B. Practice

Exercise (B1)

Show that κν→1 as ν→∞, and that s/κn−r is an unbiased estimator of σ. Compute κν for ν=1 and ν=2.

Solution. V/ν→1 in probability by the law of large numbers, and V/ν is bounded in mean square, hence uniformly integrable, so EV/ν→1. Unbiasedness: Es=σEV/(n−r)=σκn−r. For ν=1, κ1=2Γ(1)/Γ(1/2)=2/π≈0.798. For ν=2, κ2=Γ(3/2)/Γ(1)=π/2≈0.886.

Exercise (B2)

Let δ>0 be a margin below which |λ⊤β| is considered negligible. The two one-sided tests procedure declares equivalence when both H1:λ⊤β≤−δ and H2:λ⊤β≥δ are rejected by one-sided t tests at level α. Show that this happens iff the 1−2α interval Eq. 12.1.1 lies inside (−δ,δ). Show that the procedure has level α: when |λ⊤β|≥δ, the probability of declaring equivalence is at most α.

Solution. H1 is rejected iff (λ⊤β^+δ)/se>tn−r,α, that is iff the lower end of the 1−2α interval, λ⊤β^−tn−r,αse, exceeds −δ. Symmetrically H2 is rejected iff the upper end is below δ. For the level: if λ⊤β≤−δ, declaring equivalence requires rejecting H1. Write τ=σλ⊤Gλ, Z=(λ⊤β^−λ⊤β)/τ∼N(0,1) and V=SSE/σ2∼χ2(ν), ν=n−r, independent of Z (Theorem 7.5.1). The test statistic is (Z+η)/V/ν with η=(λ⊤β+δ)/τ. For every realization of (Z,V) it increases in η, so the probability that it exceeds tν,α increases in η. At η=0 that probability is α, so it is at most α whenever λ⊤β≤−δ. The case λ⊤β≥δ is symmetric.

Exercise (B3)

Suppose Y∼Nn(Xβ,σ2V) with V known and positive definite and X of full column rank. Using the generalized least squares estimator β~=(X⊤V−1X)−1X⊤V−1Y and s~2=(Y−Xβ~)⊤V−1(Y−Xβ~)/(n−p), derive an exact 1−α interval for λ⊤β. Write it out for a straight line EYi=β0+β1xi with V=diag(1/wi).

Solution. Let V=LL⊤ (Cholesky) and Z=L−1Y∼Nn(L−1Xβ,σ2I). The ordinary least squares estimate for (Z,L−1X) is β~, and its residual sum of squares is (n−p)s~2. Applying Theorem 12.1.1 to the transformed model gives λ⊤β~±tn−p,α/2s~λ⊤(X⊤V−1X)−1λ. For the weighted straight line, with x¯w=∑wixi/∑wi, y¯w defined likewise and Sw=∑wi(xi−x¯w)2, the slope estimate is β~1=∑wi(xi−x¯w)(yi−y¯w)/Sw and its interval is β~1±tn−2,α/2s~/Sw.

Exercise (B4)

In a one-way layout with a groups of sizes n1,…,na and the overparameterized model EYij=μ+αi, show that the interval for α1−α2 is y¯1⋅−y¯2⋅±tn−a,α/2s1/n1+1/n2, with n=∑ni. What does Proposition 12.1.3 say about an interval for α1 alone?

Solution. The rank is r=a. With λ=e2−e3 (coordinates μ,α1,…,αa), λ⊤β=α1−α2 is estimable, and λ⊤β^=y¯1⋅−y¯2⋅ for every least squares estimate. Its variance is σ2(1/n1+1/n2) since the group means are independent, so λ⊤Gλ=1/n1+1/n2. Substitute in Eq. 12.1.1 with n−r=n−a. The function α1 is not estimable (adding c to every αi and subtracting it from μ leaves Xβ unchanged), so every 95% confidence set for it covers every real number with probability at least 0.95.

C. Going deeper

Exercise (C1)

Among intervals [λ⊤β^−ase, λ⊤β^+bse] with a,b≥0 and coverage exactly 1−α, show that the expected length is smallest when a=b=tn−r,α/2. (Use that the t density is symmetric and strictly decreasing in |x|.)

Solution. Coverage is F(b)−F(−a), with F the t(n−r) distribution function, and the expected length is proportional to a+b. If a<b, shifting [−a,b] slightly left gains density f(a) and loses f(b)<f(a), raising the coverage, so a strictly shorter interval has coverage 1−α. Hence a=b.

Exercise (C2)

Intervals for σ2 of the form [SSE/c2, SSE/c1] with Pr(c1≤χ2(ν)≤c2)=1−α all have exact coverage. Show that the one with the smallest expected length satisfies c12f(c1)=c22f(c2), where f is the χ2(ν) density, and that the equal-tailed choice of Proposition 12.1.4 does not satisfy this condition.
