6.10  Computation

The formulas M=X(X⊤X)−X⊤ and 𝛃β^=(X⊤X)−1X⊤y are the right way to reason about least squares and the wrong way to compute it. There are two problems. M is n×n, so forming it costs O(n2) memory for a quantity that is never needed in full. And forming X⊤X squares the condition number of the problem, which can throw away half of the available floating-point digits before any equation is solved. This section shows how the geometry itself suggests the fix, which is to build an orthonormal basis for C(X). Chapter 10 develops the numerical linear algebra in full.

6.10.1. QR: Gram–Schmidt as a factorization

Apply Gram–Schmidt (Proposition 6.2.2) to the columns x1,…,xp of a full-column-rank X. Each xj is a combination of u1,…,uj with coefficients rij=ui⊤xj for i<j and rjj=‖wj‖>0. In matrix form, X=QR, where Q=[u1,…,up] is n×p with Q⊤Q=Ip, and R is p×p upper triangular with positive diagonal. This is the thin QR factorization. Since C(Q)=C(X), Proposition 6.3.2 gives M=QQ⊤ at once, and the rest of least squares follows:

𝛃Y^=Q(Q⊤y),Rβ^=Q⊤y,SSE=‖y‖2−‖Q⊤y‖2,hii=∑kqik2.
(6.10.1)

The coefficient equation holds because the normal equations become R⊤Rb=R⊤Q⊤y, and R⊤ is nonsingular. It is solved by back substitution, with no matrix inverse. Nothing of size n×n is ever formed.

In floating point, Gram–Schmidt as written in Proposition 6.2.2 gradually loses orthogonality among the computed uj. Production software computes the same factorization with Householder reflections, which are backward stable (Golub and Van Loan 2013; Higham 2002). The geometry does not change: Q is an orthonormal basis for the model space.

6.10.2. Conditioning

The sensitivity of least squares to rounding is governed by the condition number κ(X)=σmax(X)σmin(X), the ratio of the largest and smallest singular values of X (Chapter 1). Geometrically, κ(X) is large when some combination of columns of unit coefficient norm is nearly zero. The columns are then close to linearly dependent, and the coordinates of a point in C(X) are poorly determined, even though the point itself is not. The singular values of X⊤X are the squares of those of X, so κ(X⊤X)=κ(X)2.

A useful rule of thumb from numerical analysis says that solving a linear system with condition number κ in double precision loses about log10⁡κ of the roughly 16 available significant digits. The normal equations solve a system whose matrix is X⊤X, so they lose about 2log10⁡κ(X) digits. QR solves the triangular system Rb=Q⊤y, and κ(R)=κ(X) because Q has orthonormal columns, so it loses about log10⁡κ(X). The precise perturbation theory has one more subtlety. When the residual is large, the least squares problem itself has a sensitivity term proportional to 𝛆κ(X)2‖ε^‖, and no algorithm can avoid it (Higham 2002, ch. 20). QR’s advantage is largest when the model fits well.

Example (Polynomial regression)

The columns 1,t,t2,…,td evaluated at 200 equally spaced points in [0,1] become nearly dependent as d grows. To isolate the numerical error, the listing sets 𝛃y=Xβ exactly for a random 𝛃β, so that the true least squares solution is 𝛃β itself. For d=8 the condition number is 6.8×105. The normal equations return 𝛃β with relative error 1.0×10−5, while QR achieves 1.7×10−11. At d=13, with κ(X)=4.1×109, the normal-equation answer has relative error 9.3×10−1 and not one correct digit, while QR still gets 4.4×10−9. Figure 6.10.1 plots the whole sequence against the reference lines κϵ and κ2ϵ, where ϵ≈2.2×10−16 is machine precision.

import numpy as np
import statsmodels.api as sm

def fit_normal_equations(X, y):
    return np.linalg.solve(X.T @ X, X.T @ y)

def fit_qr(X, y):
    Q, R = np.linalg.qr(X)                  # X = QR, Q has orthonormal columns
    return np.linalg.solve(R, Q.T @ y)      # triangular system R b = Q'y
rng = np.random.default_rng(10)
n = 200
t = np.linspace(0, 1, n)
rows = []

for degree in range(1, 14):
    X = np.vander(t, degree + 1, increasing=True)          # 1, t, t^2, ..., t^degree
    beta = rng.normal(size=degree + 1)
    y = X @ beta                                           # exact fit: the true answer is beta
    kappa = np.linalg.cond(X)
    err_ne = np.linalg.norm(fit_normal_equations(X, y) - beta) / np.linalg.norm(beta)
    err_qr = np.linalg.norm(fit_qr(X, y) - beta) / np.linalg.norm(beta)
    rows.append((degree, kappa, err_ne, err_qr))
    print(f"degree {degree:2d}  cond(X) = {kappa:9.2e}   normal eq. {err_ne:8.1e}   QR {err_qr:8.1e}")

The polynomial example is extreme by design, but ill-conditioning is common in real data. The macroeconomic series of Longley’s classic test problem (in statsmodels.datasets.longley) give a model matrix with κ(X)≈4.86×109. Then κ(X⊤X)≈2.36×1019, which is larger than 1/ϵ. The rule of thumb predicts about 6 correct digits from QR and about 0 from the normal equations. Part of that condition number is only a matter of units: one column is a year, another is population in thousands. Rescaling columns (Theorem 6.7.1) changes κ without changing the fit (Exercise (B1)). The part that remains after rescaling reflects genuine near-dependence among the regressors, the subject of Chapter 26.

Two practical lessons follow. First, never compute (X⊤X)−1 just to obtain 𝛃β^. Solve with QR, or call a least squares routine that does. Second, reparameterizations that leave C(X) unchanged, such as centring, scaling and orthogonal polynomials, are statistically neutral but can be numerically decisive.

6.10.3. Rank deficiency and the singular value decomposition

QR with positive diagonal needs full column rank. For rank-deficient or nearly rank-deficient X, the most informative tool is the singular value decomposition X=UDV⊤=UrDrVr⊤, where U (n×n) and V (p×p) are orthogonal, D is n×p with nonnegative diagonal entries σ1≥⋯≥σr>0, and the subscript r keeps only the first r columns. Then:

  • Ur is an orthonormal basis for C(X), so M=UrUr⊤;

  • the last p−r columns of V form an orthonormal basis for N(X);

  • the Moore–Penrose inverse is X+=VrDr−1Ur⊤, and M=XX+.

Proposition 6.10.1 (Minimum-norm least squares)

𝛃β^+=X+y is a least squares estimate, and it has the smallest Euclidean norm among all least squares estimates.

Proof. XX+y=UrDrVr⊤VrDr−1Ur⊤y=UrUr⊤y=My, so 𝛃β^+ is a least squares estimate. It lies in C(Vr)=C(X⊤)=N(X)⊥. Every other least squares estimate is 𝛃β^++v with v∈N(X) (Theorem 6.4.2), and 𝛃𝛃‖β^++v‖2=‖β^+‖2+‖v‖2.

In Example (Four answers, one fit), the Moore–Penrose row is this minimum-norm solution. In floating point, “σj>0” becomes “σj larger than a tolerance”, and choosing the tolerance decides the numerical rank. That choice is a statistical decision in disguise. Chapter 10 discusses it, together with pivoted QR (Theorem 10.7.2), which gives most of the SVD’s rank-revealing ability at lower cost.

C. Going deeper

Exercise (C1)

Let X=[1,x] with x¯=c and Sxx=s2n. Find κ(X) as a function of c, s and n, and show that it grows without bound as c→∞ with s fixed. Show that centring the regressor, a reparameterization, reduces the condition number to max(1,s)/min(1,s).

Solution. Write x=c1+d with d⊥1 and ‖d‖2=ns2. Then X⊤X=n(1ccc2+s2). The matrix in parentheses has trace T=1+c2+s2 and determinant s2, so its eigenvalues are λ±=(T±T2−4s2)/2, with λ+λ−=s2 and λ+≥T/2. Hence κ(X)2=λ+λ−=λ+2s2≥T24s2→∞as c→∞. After centring, X=[1,d] has orthogonal columns of lengths n and sn, so its singular values are these lengths and κ=max(1,s)/min(1,s).
