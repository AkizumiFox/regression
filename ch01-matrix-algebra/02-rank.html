1.2  Rank, column space and null space

1.2.1. Subspaces and dimension

A nonempty set S⊆Rn is a subspace if u,v∈S and a,b∈R imply au+bv∈S. Vectors v1,…,vk are linearly independent if ∑jcjvj=0 only for c1=⋯=ck=0, that is, if the matrix [v1,…,vk] sends only the zero vector to zero. Their span is the set of all their linear combinations. A basis of S is an independent set that spans it.

We use the following facts of elementary linear algebra without proof (Halmos 1958, chapter 1). Every subspace of Rn has a basis. All bases of a subspace have the same number of elements, its dimension dim⁡S. In an r-dimensional subspace, any r independent vectors form a basis, and any independent set can be extended to a basis. If S⊆T and dim⁡S=dim⁡T, then S=T. Finally, if S∩T={0}, the union of a basis of S and a basis of T is independent, so the sum S+T={u+v:u∈S,v∈T} has dimension dim⁡S+dim⁡T. Such a sum is called direct and written S⊕T.

1.2.2. The four subspaces of a matrix

An m×n matrix A carries two subspaces of Rm and two of Rn: C(A)={Ab:b∈Rn}⊆Rm,N(A)={b∈Rn:Ab=0}⊆Rn,C(A⊤)⊆Rn,N(A⊤)⊆Rm. By Eq. 1.1.2, C(A) is the span of the columns, the column space, and C(A⊤) is the span of the rows, the row space. N(A) is the null space. The rank of A is rank(A)=dim⁡C(A), the largest number of independent columns. The number of independent rows, dim⁡C(A⊤), looks like a different quantity. It is not.

Theorem 1.2.1 (Row rank equals column rank)

For every matrix A, dim⁡C(A⊤)=dim⁡C(A). That is, rank(A⊤)=rank(A). Moreover, if rank(A)=r≥1 there are an m×r matrix B and an r×n matrix F, both of rank r, with A=BF.

Proof. Let r=rank(A) and let the columns of the m×r matrix B be a basis of C(A). Each column aj is a combination Bfj of these, so A=BF with F=[f1,…,fn]. By the transposed reading of Eq. 1.1.2, every row of A=BF is a combination of the r rows of F, so dim⁡C(A⊤)≤r=dim⁡C(A). Applying this to A⊤ gives the reverse inequality. Finally rank(F)≤r because F has r rows, and r=dim⁡C(A⊤)≤dim⁡C(F⊤)=rank(F), so rank(F)=r.

The factorization A=BF is a rank factorization: B has full column rank (its columns are independent) and F has full row rank. It is a convenient tool for proofs, as Proposition 1.9.1 shows.

Theorem 1.2.2 (Rank–nullity)

For an m×n matrix A, rank(A)+dim⁡N(A)=n.

Proof. Let v1,…,vk be a basis of N(A) and extend it to a basis v1,…,vk,w1,…,wn−k of Rn. Every Ab is a combination of Aw1,…,Awn−k, since Avi=0. These vectors are independent: if ∑jcjAwj=0, then ∑jcjwj∈N(A) is a combination of the vi, and independence of the full basis forces every cj=0. So rank(A)=n−k.

In a linear model with n×p model matrix X, dim⁡N(X)=p−rank(X) counts the directions in which the coefficient vector can move without changing the mean Xβ. X has full column rank iff N(X)={0}.

1.2.3. Rank of products and of A⊤A

Proposition 1.2.3

Let A be m×n and B be n×q.

  • (a) C(AB)⊆C(A) and N(B)⊆N(AB), so rank(AB)≤min{rank(A),rank(B)}.

  • (b) If B has full row rank, then C(AB)=C(A). If A has full column rank, then N(AB)=N(B). So rank(AB)=rank(A) in the first case and rank(AB)=rank(B) in the second. In particular, multiplying by a nonsingular matrix does not change rank.

  • (c) N(A⊤A)=N(A) and C(A⊤A)=C(A⊤), so rank(A⊤A)=rank(AA⊤)=rank(A).

  • (d) rank(A+C)≤rank(A)+rank(C) for C of the same size as A.

Proof.

  • (a) is Eq. 1.1.2, together with rank(AB)=rank(B⊤A⊤)≤rank(B⊤) by the first inclusion and Theorem 1.2.1. (b) If B has full row rank, C(B)=Rn because it is an n-dimensional subspace of Rn, so every Au equals ABv for some v. If A has full column rank, ABv=0 forces Bv=0. The rank statements follow from rank–nullity. (c) If A⊤Av=0 then ‖Av‖2=v⊤A⊤Av=0, so Av=0. Thus the null spaces agree, and by Theorem 1.2.2 rank(A⊤A)=rank(A). Since C(A⊤A)⊆C(A⊤) and both have dimension rank(A), they are equal. Applying this to A⊤ gives rank(AA⊤)=rank(A). (d) C(A+C)⊆C(A)+C(C), and the dimension of a sum is at most the sum of the dimensions.

Part (c) is the reason the normal equations X⊤Xb=X⊤y always have a solution: the right-hand side lies in C(X⊤)=C(X⊤X) (Section 1.4).

1.2.4. Nonsingular submatrices

Proposition 1.2.4

Let A have rank r≥1. Choose any r linearly independent rows, indexed by I, and any r linearly independent columns, indexed by J. Then the r×r submatrix AIJ at their intersection is nonsingular, and

A=A⋅JAIJ−1AI⋅,
(1.2.1)

where A⋅J holds the columns in J and AI⋅ the rows in I.

Proof. The columns in J are a basis of C(A), so A=A⋅JF for some r×n matrix F. Keeping only the rows in I gives AI⋅=AIJF. The left side has rank r, so by Proposition 1.2.3(a) the r×r matrix AIJ has rank r and is nonsingular. Then F=AIJ−1AI⋅, which gives Eq. 1.2.1.

Conversely, a nonsingular k×k submatrix makes the k columns of A that contain it linearly independent, so rank(A)≥k. In particular, a matrix has rank r iff it has a nonsingular r×r submatrix and no nonsingular larger one. This proposition gives an explicit generalized inverse in Theorem 1.3.2.

1.2.5. Exercises

A. Check your understanding

Exercise (A1)

Show that ∑i<j(yi−yj)2=n∑i(yi−y¯)2, and write both sides as y⊤Ay with A symmetric. Find the symmetric matrix of the quadratic form 2x12−x22+6x1x2−4x2x3.

Exercise (A2)

Show that X⊤XB=X⊤XC implies XB=XC. Deduce that X⊤Xb=0 iff Xb=0.

Solution. Put D=B−C, so that X⊤XD=0. Then (XD)⊤(XD)=D⊤X⊤XD=0, and by Eq. 1.1.3 a matrix Z with Z⊤Z=0 is zero. So XD=0. The second statement is the case C=0, with the converse obvious.

Exercise (A3)

For the additive two-way layout with two rows, three columns and one observation per cell, write the 6×6 model matrix X=[1,R,C], where R and C hold the row and column indicators. Find rank(X) and a basis of N(X). Compare [R,C]⊤ with the matrix A of Example (Filling a table from its margins).

B. Practice

Exercise (B1)

Let A be m×n and B be n×q. Prove rank(AB)≥rank(A)+rank(B)−n. Hint: apply rank–nullity to AB0, where the columns of B0 are a basis of C(B).

Solution. Let the n×s matrix B0, s=rank(B), have columns forming a basis of C(B). Then C(AB)=C(AB0), so by rank–nullity rank(AB)=s−dim⁡N(AB0). The map c↦B0c is one-to-one and sends N(AB0) into N(A), so dim⁡N(AB0)≤dim⁡N(A)=n−rank(A). Hence rank(AB)≥rank(B)−n+rank(A).

Exercise (B2)

Show that if A=B1F1=B2F2 are two rank factorizations, then B2=B1T and F2=T−1F1 for a nonsingular T.
