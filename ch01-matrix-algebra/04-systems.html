1.4  Systems of equations and consistency

A system Ax=b with A of size m×n is consistent if it has at least one solution. Least squares leads to such systems in which A=X⊤X may be singular, so we need to know when solutions exist, what all of them look like, and which features are common to all of them.

Theorem 1.4.1 (Consistency and the general solution)

Let G be any generalized inverse of A. The following are equivalent:

  • (a) Ax=b is consistent;

  • (b) b∈C(A);

  • (c) rank[A,b]=rank(A);

  • (d) AGb=b.

If the system is consistent, x0=Gb is a solution, and the set of all solutions is

{Gb+(I−GA)z:z∈Rn}=x0+N(A).
(1.4.1)

Proof. (a)⇔(b) is the first reading in Eq. 1.1.2. (b)⇔(c): appending b as a column leaves the column space unchanged iff b is already in it, and a subspace of C([A,b]) with the same dimension equals it. (d)⇒(a): Gb is a solution. (b)⇒(d): if b=Au, then AGb=AGAu=Au=b.

The solutions of a consistent system are x0+N(A), since Ax=b iff A(x−x0)=0. It remains to show N(A)=C(I−GA). The inclusion ⊇ holds because A(I−GA)=0. Conversely, if Av=0, then v=(I−GA)v.

Criterion (d) is useful in practice: it tests consistency with a single matrix product, for any generalized inverse. By Proposition 1.3.3(a) and rank–nullity, rank(I−GA)=n−r, so the solution set is an affine subspace of dimension n−r. The solution is unique iff rank(A)=n, and then Gb is the same for every G.

Idea. Any generalized inverse does three jobs for Ax=b. It tests consistency (AGb=b), produces one solution (Gb), and parametrizes all of them (Gb+(I−GA)z). Which G is used changes the particular solution but never the solution set, and a linear function q⊤x is the same across solutions exactly when q∈C(A⊤).

Corollary 1.4.2 (Invariant linear functions)

Let Ax=b be consistent and let q∈Rn. The value q⊤x is the same for every solution x iff q∈C(A⊤), that is, iff q⊤=q⊤GA for one (and then every) generalized inverse G.

Proof. By Eq. 1.4.1, q⊤x is constant over solutions iff q⊤(I−GA)z=0 for all z, that is, iff q⊤=q⊤GA. That equation puts q in C(A⊤). Conversely, if q=A⊤w, then q⊤GA=w⊤AGA=w⊤A=q⊤.

Applied to the normal equations X⊤Xb=X⊤y, which are consistent by Proposition 1.2.3(c), the corollary says that q⊤β^ is the same for all least squares solutions iff q∈C(X⊤X)=C(X⊤). This is the algebra behind estimable functions (Chapter 8).

Proposition 1.4.3 (Minimum-norm solution)

If Ax=b is consistent, then A+b is its unique solution lying in C(A⊤), and ‖A+b‖<‖x‖ for every other solution x.

Proof. A+b is a solution because A+ is a generalized inverse. From the second and fourth Penrose conditions, A+=(A+A)A+=(A+A)⊤A+=A⊤(A+)⊤A+, so A+b∈C(A⊤). Every vector of C(A⊤) is orthogonal to every v∈N(A), since (A⊤w)⊤v=w⊤Av=0. Any other solution is x=A+b+v with 0≠v∈N(A), and then ‖x‖2=‖A+b‖2+‖v‖2. The same computation shows that x∉C(A⊤), because x⊤v=‖v‖2≠0.

Example (Filling a table from its margins)

Suppose the six entries of a 2×3 table are unknown, but its row totals (9,6) and column totals (4,5,6) are known. With the cells ordered x11,x12,x13,x21,x22,x23, the equations are Ax=b with A=(111000000111100100010010001001),b=(96456). The rows of A satisfy one relation: the two row-total rows and the three column-total rows both add to 16⊤. So rank(A)=4 and there is a 6−4=2-dimensional family of solutions. The same relation must hold for b. By Theorem 1.4.1(c), the system is consistent iff the row totals and the column totals have the same sum, and here both sums are 15.

The listing builds three generalized inverses: G1 from the nonsingular submatrix in rows 1–4 and columns 1–4 (Theorem 1.3.2), the Moore–Penrose inverse G2=A+, and G3=G1+(I−G1A)Z for an integer matrix Z (Proposition 1.3.3(e)). They give the solutions \[ \begin{aligned} \G_1\bb&=(-2,\ 5,\ 6,\ 6,\ 0,\ 0)\T, & \norm{\G_1\bb}&=10.050,\ \G_2\bb&=(5/2,\ 3,\ 7/2,\ 3/2,\ 2,\ 5/2)\T, & \norm{\G_2\bb}&=6.325,\ \G_3\bb&=(21,\ -}39,\ 27,\ \ensuremath{-}17,\ 44,\ \ensuremath{-21)\T, & \norm{\G_3\bb}&=73.192.\end{aligned} \] The individual cell x11 takes the values −2, 5/2 and 21: margins do not determine cells. But x12+x13−x21 equals 5 for all three, as Corollary 1.4.2 predicts, because its coefficient vector is the first row of A minus the third. The minimum-norm solution has the additive form xij=ri/3+cj/2−15/6 in terms of the row totals ri and column totals cj (Exercise (A2)). If the last column total is changed to 7, then AGb≠b for each of the three matrices, and the script confirms that the test detects the inconsistency. The script also checks all 60 submatrices formed by 4 independent rows and 4 independent columns, and finds each one nonsingular, as Proposition 1.2.4 requires.

from fractions import Fraction
from itertools import combinations
import numpy as np
m, n = A.shape
# cells ordered (1,1), (1,2), (1,3), (2,1), (2,2), (2,3)
A = np.array([[1, 1, 1, 0, 0, 0],      # row 1 total
              [0, 0, 0, 1, 1, 1],      # row 2 total
              [1, 0, 0, 1, 0, 0],      # column 1 total
              [0, 1, 0, 0, 1, 0],      # column 2 total
              [0, 0, 1, 0, 0, 1]],     # column 3 total
             dtype=float)
b = np.array([9, 6, 4, 5, 6], dtype=float)       # both sets of totals add to 15
r = np.linalg.matrix_rank(A)
print("rank(A) =", r, " rank([A, b]) =", np.linalg.matrix_rank(np.column_stack([A, b])))

def ginverse_from_submatrix(A, rows, cols):
    """Place the inverse of the nonsingular block A[rows, cols] at [cols, rows]."""
    G = np.zeros(A.T.shape)
    G[np.ix_(cols, rows)] = np.linalg.inv(A[np.ix_(rows, cols)])
    return G

rows, cols = [0, 1, 2, 3], [0, 1, 2, 3]                  # r independent rows and columns
G1 = ginverse_from_submatrix(A, rows, cols)
G2 = np.linalg.pinv(A)                                   # Moore-Penrose inverse
rng = np.random.default_rng(1)
Z = rng.integers(-2, 3, size=A.T.shape).astype(float)
G3 = G1 + (np.eye(n) - G1 @ A) @ Z                       # another, non-reflexive one

for G in (G1, G2, G3):
    assert np.allclose(A @ G @ A, A)                     # each is a g-inverse
    assert np.allclose(A @ G @ b, b)                     # consistency test passes
    x = G @ b
    print(np.round(x, 4), " A x - b =", np.abs(A @ x - b).max())

1.4.1. Exercises

A. Check your understanding

Exercise (A1)

Find all generalized inverses of a nonzero vector a∈Rn, regarded as an n×1 matrix. Which one is a+?

Exercise (A2)

Generalize Example (Filling a table from its margins) to an a×b table with row totals ri, column totals cj and grand total T=∑iri=∑jcj. Show that xij=ri/b+cj/a−T/(ab) is a solution lying in C(A⊤), and hence is the minimum-norm solution.

Solution. Row i of the proposed table sums to ri+∑jcj/a−bT/(ab)=ri, and column j sums to ∑iri/b+cj−T/b=cj. The rows of A are the row indicators and the column indicators, so C(A⊤) consists of the tables of the form xij=αi+βj. The proposed solution has this form. By Proposition 1.4.3, it is A+b. For a=2, b=3 and T=15 this is the additive formula quoted in Example (Filling a table from its margins).

Exercise (A3)

For which c and d is the system x1+x2+x3=2, x1−x2=c, 3x1+x2+2x3=d consistent? When it is, give its general solution in the form Eq. 1.4.1.

B. Practice

Exercise (B1)

Let G be a generalized inverse of A. Show that GAG=G iff rank(G)=rank(A).

Solution. If GAG=G, then rank(G)≤rank(A) by Proposition 1.2.3(a), and rank(A)≤rank(G) by Proposition 1.3.3(a). Conversely, suppose rank(G)=rank(A)=r. Since C(GA)⊆C(G) and rank(GA)=r, the two column spaces coincide, so G=GAK for some K. Then GAG=GAGAK=GAK=G, using AGA=A.

Exercise (B2)

Let A=BF be a rank factorization. Show that A+=F⊤(FF⊤)−1(B⊤B)−1B⊤. Deduce that A+=(A⊤A)−1A⊤ when A has full column rank.

Solution. Write G for the proposed matrix. Then AG=B(B⊤B)−1B⊤ and GA=F⊤(FF⊤)−1F, both symmetric. Also AGA=B(B⊤B)−1B⊤BF=A and GAG=F⊤(FF⊤)−1FF⊤(FF⊤)−1(B⊤B)−1B⊤=G. By uniqueness G=A+. If A has full column rank, take B=A and F=I.

Exercise (B3)

Let A be m×n of rank r and let Ax=b be consistent with b≠0. Show that the system has n−r+1 linearly independent solutions and no more, and that every solution is an affine combination of them.

C. Going deeper

Exercise (C1)

Show that (A+)+=A, (A⊤)+=(A+)⊤, (A⊤A)+=A+(A+)⊤ and A+=(A⊤A)+A⊤. Give an example with (AB)+≠B+A+.
